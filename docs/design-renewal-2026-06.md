## 1. 배경

---

## 2. 디자인 토큰

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--warm` | `#C75A2E` | 오렌지 액센트 (버튼, 라벨, 아이콘, 태그) |
| `--warm-soft` | `#F5EBE2` | 연한 오렌지 배경 (태그 bg, 스텝 bg) |
| 파란 CTA | `#0066cc` | 주요 CTA 버튼 ("무료로 시작", "프로 시작하기") |
| 다크 텍스트 | `#1d1d1f` | 제목, 본문 |
| 보조 텍스트 | `#6e6e73`, `#86868b` | 설명, 메타 정보 |
| 섹션 배경 | `#f5f5f7` / `#fff` | 섹션별 교차 배경 |
| 다크 섹션 배경 | `#1d1d1f` / `#000` | 최종 CTA, 갤러리 |

**CSS 설정 (`globals.css`)**  
Tailwind v4의 `@import "tailwindcss"` 처리 순서 이슈로, `@theme inline` 블록 **뒤에** 별도 `:root` 블록으로 재선언해야 변수가 정상 적용됨.

```css
@theme inline {
  --color-warm: #C75A2E;
  --color-warm-soft: #F5EBE2;
  /* ... */
}

:root {
  --warm: #C75A2E;
  --warm-soft: #F5EBE2;
}
```

## 4. 랜딩 페이지 (로그인 전)

`app/page.tsx` — `LandingPage` 컴포넌트 (서버 컴포넌트, AppShell/SiteHeader 미사용)

### 섹션 구성

1. **Nav** — sticky, glassmorphism (`rgba(245,245,247,0.82)` + backdrop-blur)
   - 로고 (오렌지 북마크 아이콘 + "Prepper")
   - 링크: 기능 / 후기 / 가격 (각 섹션 앵커)
   - 우측: 로그인 텍스트 링크 + "무료로 시작" 파란 버튼

2. **Hero** — 배경 `#f5f5f7`
   - 뱃지 pill ("베타 오픈 · 레시피 링크 정리의 새로운 방법")
   - H1: "저장만 하던 레시피, / 이제 **요리가 됩니다**." (강조 텍스트 오렌지)
   - URL 입력 필드 + "정리하기" 파란 버튼
   - 앱 브라우저 목업 (사이드바 + 레시피 그리드 미니어처)

3. **출처 스트립** — 지원 소스 나열 (YouTube / 네이버 블로그 / 만개의레시피 / 티스토리 / 브런치)

4. **기능 소개** (`#features`) — 3-컬럼 카드
   - 유튜브·블로그 자동 정리 / 직접 추가도 간편하게 / 어디서든 동기화

5. **파싱 흐름** — 2-컬럼 (텍스트 + 레시피 카드 목업)
   - 3단계 설명 (오렌지 원형 번호)
   - 우측: 재료 태그, 오렌지 해시태그 카드 목업

6. **사용자 후기** (`#reviews`) — 2×2 그리드

7. **가격** (`#pricing`) — `PricingToggle` 클라이언트 컴포넌트
   - 월간 / 연간(−28%) 토글
   - 무료 / 프로 요금제 카드 (프로: 파란 보더 + "가장 인기 있는" 뱃지)

8. **최종 CTA** — 다크 배경 (`#1d1d1f`)

9. **Footer** — 4-컬럼 (브랜드 소개 / 제품 / 회사 / 지원)

## 5. 앱 화면 (로그인 후)

`app/page.tsx` — `AppHome` 컴포넌트 (서버 컴포넌트, AppShell 미사용)

### 레이아웃

```
┌──────────────────────────────────────────┐
│  사이드바 (264px)  │  메인 영역           │
│                    │  ┌── 탑바 (64px) ──┐ │
│  로고              │  │ 검색 + 아바타    │ │
│  [링크 추가] 버튼  │  └─────────────────┘ │
│                    │                      │
│  컬렉션 목록       │  전체 레시피 N개     │
│  ─ 전체 레시피     │  [링크 추가] 버튼    │
│  ─ YouTube         │                      │
│  ─ 블로그·웹       │  레시피 그리드       │
│  ─ 즐겨찾기        │  + 우측 상세 패널    │
│  ─ 확인 필요       │                      │
│                    │                      │
│  유저 프로필       │                      │
│  로그아웃          │                      │
└──────────────────────────────────────────┘
```

### 사이드바 상세
- 배경: `#f5f5f7`, 우측 보더: `#e8e8eb`
- "링크 추가" 버튼: 오렌지 배경 → 클라이언트 상태 모달 오픈
- 컬렉션 활성 항목: 오렌지 배경 (`rgba(199,90,46,0.1)`) + 오렌지 텍스트
- 유저 아바타: 이메일 첫 글자, 하단 고정

### 메인 상세
- 탑바: glassmorphism, 검색 인풋 (현재 비기능 — 텍스트 placeholder), 검토 필요 뱃지
- 콘텐츠: `auto-fill, minmax(230px, 1fr)` 그리드
- 카드 클릭: 저장된 레시피는 `/?recipe=ID`로 이동하며 홈 우측 상세 패널 표시
- 확인 필요 카드: `/?review=ID` 빠른 보정 모달 표시

### 레시피 카드 (`RecipeGridCard` / `RecipeCard`)
- 썸네일: 그라디언트 (YouTube → 오렌지 계열 / 블로그 → 초록 계열)
- 소스 뱃지: 왼쪽 상단 반투명 검정
- "확인 필요" 뱃지: 오른쪽 상단 노란색
- 메타: `재료 N개 · servings`

## 6. 라우팅 정리

로그인 후 웹은 홈을 단일 작업 공간으로 사용한다.

- `/`: 비로그인 랜딩 + 로그인 앱 홈
- `/?recipe=ID`: 홈 우측 상세 패널
- `/?review=ID`: 홈 빠른 보정 모달
- `/recipes/[id]`: 호환 redirect → `/?recipe=ID`
- `/recipes/[id]/review`: 호환 redirect → `/?review=ID`
- 삭제: `/recipes`, `/recipes/new`
